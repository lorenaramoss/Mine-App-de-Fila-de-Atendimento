
# Mini App de Fila de Atendimento

Sistema web desenvolvido em Python utilizando Flask e SQLite para gerenciamento de fila de atendimento.

## Funcionalidades

- Cadastro de clientes
- Fila de espera
- Chamada do próximo cliente
- Ordem FIFO
- Status do atendimento
- Cancelamento
- Prioridade Normal e Preferencial
- Histórico de atendimentos

## Tecnologias

- Python
- Flask
- SQLite
- HTML5
- CSS3
